# Part 2 · Chapter 5. 아이디어가 막힐 때 브레인스토밍

책 Part 2 · 5장의 프롬프트입니다. 회색 상자 내용을 복사해 클로드에 붙여 넣고, `[ ]` 부분만 본인 상황에 맞게 바꿔 쓰세요.


## 5-1

**프롬프트**

```text
당신은 10년차 브랜드 마케팅 전략가입니다.
아래 조건으로 [브레인스토밍 주제 — 예: 신규 마케팅 이벤트] 아이디어를 브레인스토밍해 주세요.
배경:
- 회사: [업종 및 타깃 — 예: B2C 생활용품 브랜드(20~30대 타깃)]
- 시기: [기획 시기 — 예: 2분기(4~6월)]
- 목적: [기획 목적 — 예: MZ세대 신규 고객 유입 + 브랜드 인지도 향상]
- 예산 규모: [예산 수준 — 예: 중간(대규모 광고 캠페인은 어렵고, 온라인 중심 가능)]
요청:
- 아이디어를 [개수 — 예: 5]가지 이상, 카테고리별로 분류해 제시
- 각 아이디어마다 핵심 콘셉트, 기대 효과, 예상 난이도를 한 줄로 정리
- 서로 성격이 다른 아이디어를 섞어 주세요([다양성 기준 — 예: 온라인/오프라인, 참여형/콘텐츠형 등])
```

**심화 프롬프트**

```text
위 아이디어 중 [선택한 아이디어 — 예: 1번 “#나만의루틴 챌린지”와 2번 “이 조합 실화냐 활용법 공모전”]이 현
실적으로 좋아 보입니다.
이 [개수 — 예: 두] 가지를 각각 다음 항목으로 구체화해 기획안 초안을 만들어 주세요.
- 진행 기간 및 주요 일정
- 필요한 준비물과 담당 부서
- 예상 참여자 수(보수적/낙관적 시나리오)
- 성공 기준(KPI) [KPI 개수 — 예: 3]가지
- 예상되는 리스크 1~2가지와 대응 방안
```


## 5-2

**프롬프트**

```text
당신은 [검토자 역할 — 예: 까다롭기로 유명한 전략기획실 임원]입니다.
아래 [문서 유형 — 예: 기획안]을 비판적인 시각으로 검토해 주세요. 칭찬보다는 논리적 허점, 빠진 내용, 실행 가
능성의 문제를 중심으로 피드백해 주세요.
기획안:
[여기에 검토받고 싶은 기획안 전체 내용을 붙여 넣거나 파일을 첨부해 주세요]
검토 요청 사항:
- 논리적 비약이나 근거가 부족한 주장이 있는지
- 빠져 있는 항목이나 고려하지 않은 관점이 있는지
- 실행 단계에서 발생할 수 있는 현실적 문제
- 수치나 데이터의 신뢰성(출처가 명확한지)
- 개선 제안을 항목별로 정리해 주세요
```

**심화 프롬프트(사내 공지 변환)**

```text
위에서 지적한 [보완할 항목 — 예: 공통 문제 1번(수치 근거 부재)과 1번 기획안의 ‘바이럴 메커니즘 부재’]을 반영
해, 해당 섹션을 보완해 주세요.
조건:
- [보완 방향 1 — 예: 예상 참여자 수는 가상 데이터를 만들지 말고, “이런 데이터를 확인해 넣으세요”라고 안내해
주세요]
- [보완 방향 2 — 예: 챌린지 확산을 위한 구체적 메커니즘(지목 릴레이, 밈 요소 등)을 제안해 주세요]
- [보완 방향 3 — 예: 캠페인별 예산 항목표를 개략적으로라도 작성해 주세요]
```


## 5-3

**프롬프트**

```text
당신은 [역할 — 예: 10년차 프레젠테이션 컨설턴트]입니다.
아래 조건으로 발표 자료의 스토리라인을 설계해 주세요.
발표 정보:
- 주제: [발표 주제 — 예: 2분기 신규 마케팅 채널(숏폼 영상) 도입 기획]
- 발표 시간: [발표 시간 — 예: 15분 발표 + 5분 Q&A]
- 청중: [청중 구성 — 예: C레벨 임원 3명(CEO, CMO, CFO)]
- 목적: [발표 목적 — 예: 기획안 승인(예산 배정 의사결정)]
청중 특성:
- [청중 1]: [관심사 — 예: CEO: 큰 그림과 성장 전략에 관심, 디테일보다 방향성]
- [청중 2]: [관심사 — 예: CMO: 마케팅 ROI와 브랜드 임팩트에 관심]
- [청중 3]: [관심사 — 예: CFO: 비용 대비 효과, 리스크 관리에 관심]
요청:
- 슬라이드 [장수 — 예: 10~12]장 구성으로 스토리라인 제시
- 각 슬라이드의 핵심 메시지(Key Message)를 한 줄로
- 발표자 스크립트 핵심 포인트를 슬라이드별 2~3줄로
- 예상 Q&A [개수 — 예: 3]가지와 답변 방향도 준비
- PPT 파일이 아닌 텍스트 형태로 출력해 주세요
```

**심화 프롬프트**

```text
위 스토리라인을 기반으로 실제 PPTX 파일을 만들어 주세요.
조건:
- 위의 스토리라인 구조와 핵심 메시지를 그대로 반영
- 슬라이드당 제목 + 핵심 메시지 + 스크립트 포인트 포함
- 디자인 톤: [원하는 스타일 — 예: 깔끔하고 미니멀한 비즈니스 스타일]
- 데이터가 필요한 부분은 [여기에 실제 수치 입력]으로 표시
- 각 슬라이드에 발표자 노트도 함께 작성
- 파일 형식: PPTX
```


## 5-4

**프롬프트**

```text
당신은 [역할 — 예: 까다롭기로 유명한 C레벨 임원]입니다.
아래 발표에 대해 청중의 반응을 시뮬레이션하고, 발표자가 준비해야 할 대응 전략을 제시해 주세요.
발표 상황:
- 발표 주제: [발표 주제 — 예: 2분기 숏폼 마케팅 채널 도입 기획안]
- 발표 시간: [발표 시간 — 예: 15분 발표 + 5분 Q&A]
- 청중: [청중 구성 — 예: CEO, CMO, CFO]
- 발표 목적: [발표 목적 — 예: 기획안 승인 및 예산 배정]
청중별 관심사:
- [청중 1]: [관심사 — 예: CEO: 성장 전략과 시장 선점에 관심]
- [청중 2]: [관심사 — 예: CMO: 브랜드 일관성과 마케팅 ROI에 관심]
- [청중 3]: [관심사 — 예: CFO: 비용 대비 효과와 리스크 관리에 관심]
요청:
- 최선의 시나리오(즉석 승인), 기본 시나리오(조건부 승인), 최악의 시나리오(보류/반려) 세 가지 제시
- 각 시나리오에서 청중이 할 수 있는 질문/반응을 구체적인 발언으로 예시
- 각 발언에 대한 발표자의 대응 멘트를 준비해 주세요
- 발표자가 절대 양보하면 안 되는 선(Bottom Line)도 제안해 주세요
```

**심화 프롬프트**

```text
위의 [심화할 시나리오 — 예: ‘최악의 시나리오(보류/반려)’]를 더 깊이 시뮬레이션해 주세요.
- [ 청중]이 [핵심 반박 — 예: “ROI 보장 없이 예산을 쓸 수 없다”]라고 했을 때, 후속 질문 [개수 — 예: 3]가지와
각각의 대응
- 발표가 보류될 조짐이 보일 때의 마무리 멘트
- 발표 후 [후속 조치 — 예: 24시간 이내에 보낼 팔로업 이메일 초안]
```

# Part 2 · Chapter 3. 글쓰기의 고통에서 해방되다

책 Part 2 · 3장의 프롬프트입니다. 회색 상자 내용을 복사해 클로드에 붙여 넣고, `[ ]` 부분만 본인 상황에 맞게 바꿔 쓰세요.


## 3-1

**프롬프트**

```text
당신은 10년차 비즈니스 커뮤니케이션 전문가입니다.
아래 상황에 맞는 비즈니스 이메일을 작성해 주세요.
상황:
- 수신자: [거래처명] [담당자 이름] [직급]
- 목적: [메일 목적 — 예: 납기 지연 안내 및 양해 요청]
- 배경: [품목] [수량], 원래 [기존 일정] → 변경 [새 일정] ([지연 사유])
- 우리 회사에서 취할 조치: [대안 — 예: 긴급 물량 100개는 3/18 선납품 가능]
조건:
- 톤: [원하는 톤 — 예: 정중하고 신뢰감 있는 비즈니스 톤]
- 분량: [분량 — 예: 300]자 내외
- 형식: [이메일 구조 — 예: 인사 → 본론(지연 사유 + 변경 일정) → 대안 제시 → 마무리]
- 발신자: [소속] [이름] [직급]
- 서명 형식: [이름 + 직급만 / 이름 + 직급 + 연락처]
```

**심화 프롬프트**

```text
위 이메일에서 다음을 추가로 반영해 주세요.
- 참조 수신자(CC)가 [CC 인원 수]명 있습니다: [CC 수신자 목록과 각각의 역할]
- [ CC 수신자들이 읽을 때 어떤 인상을 줄지 — 예: 우리 팀이 적극 대응 중이라는 점과 일정 변경이 합리적인 조
치라는 점이 자연스럽게 드러나도록] 작성해 주세요
- 본문 하단에 간단한 [추가할 요소 — 예: 일정 비교표]를 추가해 주세요
- 분량 제한 없이, 적절한 길이로 작성해 주세요
```


## 3-2

**프롬프트 (Step 1: 뼈대 잡기)**

```text
당신은 [분야 — 예: 마케팅] 기획 10년차 전문가입니다.
아래 주제로 기획서 목차를 잡아 주세요.
주제: [기획서 주제 — 예: 2분기 신규 마케팅 채널(숏폼 영상) 도입 기획서]
목적: [보고 대상 — 예: 팀장 → 임원 보고용]
우리 회사 상황: [현재 상황 요약 — 예: B2C 생활용품 브랜드, 현재 블로그·인스타그램 중심으로 마케팅 운영 중]
조건:
- 목차는 [항목 수 — 예: 8]개 항목으로 구성
- 각 항목마다 포함할 핵심 내용을 한 줄로 설명
- 임원이 납득할 수 있는 논리적 흐름으로 배치
- 분량 기준: 전체 A4 [장 수]장 이내
```

**프롬프트 (Step 2: 살 붙이기)**

```text
위 목차에서 ‘[상세 작성할 항목명]’ 항목을 상세히 작성해 주세요.
조건:
- 분량: [분량 — 예: 500~700]자
- [포함할 내용 — 예: 콘텐츠 유형별 예시를 구체적으로 포함]
- [추가 요소 — 예: 주 2회 발행 기준 월간 콘텐츠 캘린더 초안 포함]
- 경어체, 보고서 톤
- 필요시 표나 그래프 설명을 포함
```

**프롬프트 (Step 3: 톤 통일)**

```text
위 기획서 전체 내용의 문체를 통일해 주세요.
조건:
- [문체 — 예: 경어체(합쇼체)]로 통일
- 수치가 나오는 부분은 표로 정리
- 각 섹션 분량이 지나치게 차이 나지 않도록 조정
- 문장은 간결하게 (한 문장 60자 이내)
```


## 3-3

**프롬프트 (톤 미지정 - Before)**

```text
[공지 내용 — 예: 다음 주 월요일에 전사 시스템 점검이 있습니다.]
[영향 범위 — 예: 9시부터 12시까지 사내 인트라넷 접속이 안 됩니다.]
이 내용으로 사내 공지를 써줘.
```

**심화 프롬프트(톤 지정 - After)**

```text
아래 내용으로 사내 공지를 작성해 주세요.
내용:
- [공지 항목 1 — 예: 다음 주 월요일(3/10) 전사 시스템 점검]
- [공지 항목 2 — 예: 09:00~12:00 사내 인트라넷 접속 불가]
- [공지 항목 3 — 예: 사전에 필요한 자료는 미리 다운로드 요망]
톤 지정:
- 우리 회사 공지 스타일: [스타일 설명 — 예: 핵심 정보를 먼저, 부가 설명은 뒤에]
- [톤 설명 — 예: 딱딱하지 않지만 격식은 갖춘 톤]
- 아래 예시 문장과 같은 느낌으로 작성
예시: “[우리 회사에서 실제 쓰는 문장 2~3개 — 평소 잘 썼다고 느낀 이메일이나 공지에서 골라 보세요]”
형식:
- [원하는 형식 — 예: 제목 + 본문 (200자 내외) + 문의처]
```


## 3-4

**프롬프트**

```text
당신은 [브랜드 유형 — 예: B2C 생활용품] 브랜드의 SNS 마케팅 담당자입니다.
아래 내용으로 인스타그램 게시물 캡션을 작성해 주세요.
원본 내용:
- 제품명: [제품명]
- 핵심 특징: [특징 1], [특징 2], [특징 3]
- 출시일: [출시일]
- 가격: [정가] ([할인 조건] → [할인가])
- 핵심 메시지: [한 줄 메시지]
조건:
- 분량: [분량 — 예: 150]자 내외
- 톤: [원하는 톤 — 예: 친근하고 감성적, 20~30대 직장인 타깃]
- 해시태그 [개수]개 포함
- 첫 줄에서 시선을 끌 것
```

**심화 프롬프트(사내 공지 변환)**

```text
같은 내용을 사내 공지용으로 바꿔 주세요.
조건:
- 톤: [톤 — 예: 격식체, 사내 직원 대상]
- 형식: [형식 — 예: 제목 + 핵심 정보(불릿) + 마케팅팀 협조 요청]
- 분량: [분량 — 예: 200]자 내외
- 목적: [공지 목적 — 예: 전 직원에게 신제품 출시 사실 공유 및 SNS 홍보 협조]
- 발신자: [발신 부서 및 담당자 이름 — 예: 마케팅팀 이주영 대리]
```

**심화 프롬프트(뉴스레터 변환)**

```text
같은 내용을 고객 대상 뉴스레터용으로 바꿔 주세요.
조건:
- 톤: [톤 — 예: 브랜드 뉴스레터 톤 (친절하면서 신뢰감)]
- 형식: [형식 — 예: 제목 + 인사말 + 제품 소개 + 할인 혜택 + 행동 유도 문구]
- 분량: [분량 — 예: 300]자 내외
- 행동 유도: [원하는 행동 — 예: 사전 예약 페이지 방문 유도]
```

# Part 4 · Chapter 10. 회의를 30분으로 끝내는 법

책 Part 4 · 10장의 프롬프트입니다. 회색 상자 내용을 복사해 클로드에 붙여 넣고, `[ ]` 부분만 본인 상황에 맞게 바꿔 쓰세요.


## 10-2

**프롬프트**

```text
오늘 오후에 예정된 회의를 확인하고, 회의 준비를 도와줘.
- 캘린더에서 회의 찾아서 개요(제목, 시간, 참석자) 정리
- 관련 Notion 문서나 Google Drive 파일이 있으면 핵심 요약
- 지난 회의 결정 사항 + 이번 회의 예상 안건 + 내가 준비할 자료 목록
```

**심화 프롬프트**

```text
[Notion ‘회의 브리핑 자료’ 페이지 URL 붙여 넣기]
이 페이지 하위에 오늘자 회의 브리핑 시트 페이지를 만들고, 거기에 회의에 가져갈 A4 1장 분량의 브리핑 시트를 만들어 줘.
구성: 회의 개요 → 지난 회의 미결 사항 → 이번 논의 안건 → 의사결정 항목별 선택지(장단점 포함)
```


## 10-3

**프롬프트**

```text
[Notion ‘회의록’ 페이지 URL 붙여 넣기]
아래 회의 메모를 회의록으로 정리해 위 페이지 하위에 저장해 줘.
핵심 논의 → 결정 사항 → 액션 아이템(담당자+기한, 표) → 보류/다음 회의 안건
[회의 메모 붙여 넣기 또는 파일 첨부]
```

**심화 프롬프트**

```text
위 회의록의 액션 아이템을 Google Calendar에 일정으로 등록해 줘.
- 각 액션 아이템의 기한을 마감일로, 제목에 담당자와 할 일을 포함
- 업무 의존 관계가 있으면 선행 항목의 기한을 먼저 배치
- 일정 설명에 회의에서 논의된 배경 한 줄 추가
```


## 10-4

**프롬프트**

```text
위 회의록을 바탕으로 참석자에게 보낼 요약 메일을 작성해 Gmail 초안으로 저장해 줘.
수신자: [참석자 이메일 주소들]
핵심 결정 사항 + 담당자별 액션 아이템(담당자+기한) + 다음 회의 예고
```

**심화 프롬프트**

```text
위 회의록을 바탕으로 참석자별 요약 메일을 각각 다른 톤으로 여러 버전 만들어 대화창에 카드로 보여 줘.
수신자: [참석자 이메일]
- 박지훈 팀장에게는 격식체, 나머지 동료에게는 편한 톤
- 각 메일에 해당 참석자의 액션 아이템 강조
- 확인 후 Gmail 초안으로 저장해 줘
```

# Part 3 · Chapter 7. Connectors: 업무 도구 연동하기

책 Part 3 · 7장의 프롬프트입니다. 회색 상자 내용을 복사해 클로드에 붙여 넣고, `[ ]` 부분만 본인 상황에 맞게 바꿔 쓰세요.


## 7-2

**프롬프트**

```text
아래 회의 메모를 정리해서, 이 Notion 페이지에 새 하위 페이지로 만들어 주세요.
Notion 페이지 링크: [Notion ‘주간 회의록’ 페이지 URL을 붙여 넣기]
회의 정보:
- 회의명: [회의명 — 예: 주간 팀 회의]
- 일시: [일시 — 예: 2025년 3월 12일(수) 15:00~16:00]
- 참석자: [참석자 — 예: 팀장 박지훈, 이주영, 김태호, 정유라]
회의 메모:
[여기에 회의 중 적은 메모를 그대로 붙여 넣기]
예시:
- 팀장: Q2 마케팅 예산 10% 삭감 확정, 숏폼 중심으로 전환
- 태호: SNS 광고 성과 보고 → 인스타 CTR 2.1%, 틱톡 3.8%
- 유라: 신제품 런칭 일정 4/15 → 4/22로 변경(디자인 지연)
- 주영: 경쟁사 분석 보고서 다음 주 월요일까지
- 전체: 다음 회의 3/19(수) 같은 시간
정리 형식:
- 핵심 결정 사항(번호 목록)
- 액션 아이템(담당자 | 내용 | 기한 — 표 형식)
- 다음 회의 일정
- Notion 페이지 제목: “[날짜] 주간 팀 회의록”
```

**심화 프롬프트**

```text
방금 만든 Notion 회의록을 내가 직접 수정했어. 현재 페이지를 확인하고 아래 작업을 해 줘.
- 상단에 회의 목적 한 줄 요약 추가
- 액션 아이템 표에 ‘진행 상태’ 컬럼 추가(기본값: 미시작)
- 하단에 “이전 회의 대비 달라진 점” 섹션을 새로 만들어 줘
```


## 7-3

**프롬프트**

```text
내 Gmail에서 [날짜 — 예: 지난 금요일(3/7)] 이후 받은 메일을 확인하고, 아래 형식으로 정리해 줘.
분류 기준:
- “긴급, 중요, 참고”로 각각 색상 이모지를 붙여 분류
정리 형식:
각 분류별로:
- 발신자, 제목, 핵심 내용 한 줄 요약, 필요한 액션
긴급 메일에는 필요한 액션도 함께 정리해 줘.
```

**심화 프롬프트**

```text
긴급 메일 2건에 대해 답장 초안을 작성해서 Gmail 임시보관함에 저장해 줘.
A사 김민수 과장:
- 기한(3/14) 경과에 대한 사과 + 내부 검토 완료 예정일(3/18) 명시
- 3가지 변경 사항에 대해 항목별로 우리 쪽 입장을 간략히 언급
- 톤: 정중하지만 적극적으로 대응하고 있다는 인상
박지훈 팀장:
- 수요일 회의 전 초안 공유 약속 + 사전 논의 포인트 2~3개를 질문으로 포함
- 톤: 적극적이면서 협조적인 느낌
```


## 7-4

**프롬프트**

```text
내 Google Calendar에서 [날짜 — 예: 내일] 일정을 확인하고, 각 회의에 대해 아래 형식으로 준비 브리핑을 만
들어 줘.
각 회의별 정리 형식:
- 회의명, 시간, 참석자
- 회의 목적(추정)
- 내가 준비해야 할 것(구체적으로)
- 예상 소요 준비 시간
추가 요청:
- 회의 간 이동 및 준비 시간을 고려해, 어떤 순서로 준비하면 효율적인지 추천해 줘
- 가장 긴급한 준비 사항에 [긴급] 태그 표시
- 브리핑 카드 형식으로 만들어 줘
```

**심화 프롬프트**

```text
거래처 미팅 준비 자료를 만들어 줘.
- 지난 분기 거래 현황 요약(표 형식: 월별 발주량, 납품 현황, 이슈)
- 이번 주 메일에서 논의된 계약 조건 변경 포인트 정리
- 미팅에서 우리 쪽이 제안할 수 있는 협상 포인트 2~3개
정리가 끝나면 이 내용을 Notion 페이지로 만들어 줘.
Notion 페이지 링크: [Notion ‘거래처 미팅 준비’ 페이지 URL을 붙여 넣기]
```

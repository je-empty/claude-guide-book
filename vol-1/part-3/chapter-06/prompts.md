## 6-2

**프롬프트**

```text
나는 아래 상황의 직장인이야.
- 회사: B2C 생활용품 브랜드(직원 약 200명)
- 소속: 마케팅팀, 3년차 대리
- 주요 업무: 주간 마케팅 보고서 작성, 거래처 이메일, SNS 콘텐츠 기획
- 보고 대상: 마케팅팀장
- 주로 다루는 주제: 숏폼 마케팅, 인스타그램·틱톡 운영, 브랜드 콘텐츠 기획
- 글쓰기 규칙: 보고서는 경어체(합쇼체), A4 2장 이내, 숫자에는 출처 필수
위 정보를 바탕으로, 클로드 Projects의 ‘지침’에 넣을 내용을 마크다운 형식으로 만들어 줘.
항목별로 구조화해서, 복사해서 바로 붙여 넣을 수 있게 해 줘.
```


## 6-3

**프롬프트**

```text
이번 주 숏폼 마케팅 성과 보고서 초안 써 줘.
이번 주 수치:
- 릴스 평균 조회수: 3,200(전주 2,800)
- 틱톡 팔로워: 1,800명(전주 1,500)
- 이번 주 발행: 릴스 3건, 틱톡 2건
```

**심화 프롬프트**

```text
이번 주 숏폼 마케팅 성과 보고서를 써 줘.
업로드한 지난주 보고서와 같은 양식으로 작성해 줘.
이번 주 수치:
- 릴스 평균 조회수: 3,200(전주 2,800)
- 틱톡 팔로워: 1,800명(전주 1,500)
- 자사몰 유입 전환율: 1.2%(전주 0.9%)
- 이번 주 발행 콘텐츠: 릴스 3건, 틱톡 2건
```


## 6-4

**프롬프트**

```text
지금까지 이 프로젝트에서 나눈 대화를 바탕으로,
내 프로젝트 지침에 추가하면 좋을 내용을 정리해 줘.
정리 기준:
- 여러 번 반복해서 요청한 패턴이 있으면 규칙으로 제안
- 내가 자주 수정을 요청한 부분이 있으면 선호사항으로 제안
- 새로 파악된 정보(경쟁사 변화, 전략 수정 등)가 있으면 업데이트 항목으로 제안
항목별로 나눠서, 복사해서 바로 지침에 붙여 넣을 수 있는 형태로 정리해 줘.
```

**심화 프롬프트**

```text
위에서 제안한 내용을 모두 반영해서, 새로운 프로젝트 지침을 전체 다시 작성해 줘.
기존 지침의 구조는 유지하되, 다음을 반영:
- 틱톡 팔로워 목표 8,000으로 상향
- B사 틱톡 진출 현황 추가
- 보고서 마지막에 ‘다음 주 액션 플랜’ 섹션 필수 포함
- 경쟁사 비교는 A사를 최우선 벤치마크로
- 성과 데이터는 표로 정리, 서술은 간결하게
마크다운 형식으로, 복사해서 바로 기존 지침을 대체할 수 있게 작성해 줘.
```

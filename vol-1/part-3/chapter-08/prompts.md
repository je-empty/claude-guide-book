# Part 3 · Chapter 8. Skills: 회사 규칙 영구 등록하기

책 Part 3 · 8장의 프롬프트입니다. 회색 상자 내용을 복사해 클로드에 붙여 넣고, `[ ]` 부분만 본인 상황에 맞게 바꿔 쓰세요.


## 8-2

**프롬프트**

```text
나는 [직무 — 예: 마케터 / 기획자 / PM / 영업 / HR]이야.
내 업무 스타일에 맞는 Skills를 만들어 줘.
아래 내용을 반영해 만들어 줘.
1. 글쓰기 스타일
- 기본 문체 [예: 보고서는 경어체(합쇼체), SNS 초안은 반말체]
- 선호하는 답변 구조 [예: 핵심 먼저, 배경 설명은 뒤에]
- 이메일 서명 형식 [예: “감사합니다. 마케팅팀 이주영 드림”]
2. 보안 및 기밀 규칙
- 외부 공유 금지 정보의 처리 방식 [예: 미확정 매출은 “약 ~억 원대”로 범위 표기]
- 고객사/파트너사 표기 규칙 [예: 실명 대신 A사, B사 등 알파벳 코드]
3. 출력 형식 선호
- 표/리스트/서술 중 선호하는 형식 [예: 성과 데이터는 반드시 표로 정리]
- 숫자 데이터 표기 기준 [예: 전주/전월 대비 증감률 항상 포함]
4. 업무 용어 및 맥락
- 자주 쓰는 업무 용어와 약어 설명 [예: CTR=클릭률, CVR=전환율, “소재”=광고 크리에이티브]
- 팀 내 커뮤니케이션 규칙 [예: 팀장 보고용은 요약 중심, 실무 공유용은 상세 데이터 포함]
```

**심화 프롬프트**

```text
이번 주 숏폼 캠페인 성과를 팀장 보고용으로 정리해 줘.
주요 수치:
- 릴스 평균 조회수: 4,500
- 틱톡 팔로워: 3,200명
- 자사몰 유입 전환율: 1.8%
- B사가 이번 주 신규 챌린지 캠페인 시작
```


## 8-3

**프롬프트**

```text
우리 회사의 보안 가이드라인을 적용하는 Skills를 만들어 줘.
아래 정보를 기반으로 작성해 줘.
회사 정보 보안 등급:
- 1등급(극비): [예: 미공개 인수합병 정보, 핵심 기술 특허]
- 2등급(대외비): [예: 분기 매출, 신규 계약 조건, 인사 정보]
- 3등급(일반): [예: 공개된 회사 소개, 채용 공고 내용]
적용할 규칙:
- 1등급 정보: 절대 입력하지 않기(입력 자체를 금지하는 경고 문구)
- 2등급 정보: 범위값으로 변환해 표기(예: “약 50억 원대”)
- 고객/파트너사: 실명 대신 알파벳 코드(A사, B사)
- 직원 개인정보: 이름 대신 직급+부서로 표기
```

**심화 프롬프트**

```text
ㅇㅇ사와 진행 중인 공동 마케팅 제안서 초안을 작성해 줘.
포함할 내용:
- 이번 분기 자사 매출 42억 원 기준 협업 규모 산정
- ㅇㅇ사 담당자 [담당자명 — 예: 김민수 과장]에게 보낼 이메일 형식
- 캠페인 예산 배분 제안
```

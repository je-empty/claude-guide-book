## 🚀 프롬프트, 어떻게 복사하나요??

1. 아래 **목차**에서 지금 읽고 있는 Part을 클릭합니다.
2. 실습중인 프롬프트의 **회색 상자** 내용을 복사합니다. _(상자 오른쪽 위 작은 사각형 복사 버튼을 누르면 한 번에 복사됩니다.)_
3. 클로드 입력창에 붙여 넣고, 문장 속 **`[ ]` 부분을 본인 상황에 맞게** 수정해서 사용할 수 있습니다.

> 💡 프롬프트는 **Part → Chapter → 절** 순서로 정리되어 있습니다.

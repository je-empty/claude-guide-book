## 🚀 프롬프트, 이렇게 쓰세요

1. 아래 **목차**에서 지금 읽고 있는 장을 누릅니다.
2. 원하는 프롬프트의 **회색 상자** 내용을 복사합니다. _(상자 오른쪽 위 복사 버튼을 누르면 한 번에 복사돼요.)_
3. 클로드 입력창에 붙여 넣고, 문장 속 **`[ ]` 부분을 본인 상황에 맞게** 바꿔서 보냅니다.

> 💡 프롬프트는 **Part → Chapter → 절** 순서로 정리돼 있습니다.
